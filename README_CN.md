# VoidFemboy 虚空伪娘

[English](https://github.com/Ripmrlukas/voidfemboy/blob/main/README.md) | 简体中文

一款Pastel Void主题的Fabric模组，支持 **Minecraft 1.21.1 和 1.20.1**：添加了虚空矿物、一套真3D可染色“伪娘”套装（带 **可穿戴的45格连帽衫口袋**）、用于染色的可爱工作台、银河标题画面、游戏内配方书“虚空圣典”，以及一些小秘密哦。喵~

> 本仓库仅用于 **问题反馈和功能请求** —— 模组源代码不在此发布。请从 Modrinth / CurseForge 获取模组。
> 模组目前 **闭源** —— 未来可能会开源。

## 功能特性

- **虚空盔甲** —— 一套银河材质的套装，强度高于钻石，拥有发光流动的银河纹理，套装效果为生命恢复 + 力量。
- **伪娘套装** —— 一套真3D GeckoLib装扮（猫耳发箍、连帽衫、带物理裙摆和尾巴的连衣裙、条纹过膝袜、猫爪小靴子）。穿上全套可获得装饰性效果 **“自信”**。
- **伪娘尾巴 & 猫耳耳机** —— 额外的装饰槽（通过“可爱菜单”，按键 `X`）：带有物理摆动效果、末端白色的尾巴，以及厚实的耳机耳罩和随头部转动的头梁。两者均可染色；耳机部件在第一人称视角下会自动隐藏。
- **连帽衫口袋** —— 连帽衫 / 连帽连衣裙自带一个 **45格的口袋**（9×5）。默认按键 `N` 可开关口袋界面，穿戴时生效。口袋内容会随物品一起保存，包括关闭界面、重新登录、卸下装备 **甚至死亡** 都不会丢失。
- **随心搭配** —— 可单穿连帽衫（无裙摆）、单穿连衣裙（胸甲槽位），或穿连帽连衣裙。穿戴臂套时，袖子会自动隐藏。
- **染色** —— 在 **可爱工作台** 中为任意伪娘部件染色：16色彩虹色板 + 完整的HSV拾色器，支持十六进制颜色输入，可单独染色各部件，也可 **一键染全部**（包括盔甲）。物品驱动的纸娃娃模型会清晰显示每个部件覆盖的身体区域。支持切换 **条纹或纯色**，点击 **清除** 可恢复默认。
- **无声爪爪** —— 猫爪小靴子行走时不会发出脚步声。
- **虚空圣典** —— 一个可爱的配方浏览界面，可从暂停菜单打开，背景与自定义标题画面使用同样的动态银河背景。
- **布罗艾** —— 一个软软的鲨鱼毛绒方块，会转向面对你。右键点击会发出吱吱声，潜行 + 右键可将其捡起。
- **兼容性** —— 与 Iris/Sodium、First-person Model、JEI 以及大型整合包良好兼容（已在 1.20.1 的 AOF7 中测试）。

## 版本与下载

两个发布线，功能相同 —— 请根据你的游戏版本选择：

| Minecraft | 模组文件 | 要求 |
|---|---|---|
| 1.21.1 | `voidfemboy-0.2.0-alpha.jar` | Java 21，Fabric API，GeckoLib 4.7+ |
| 1.20.1 | `voidfemboy-0.2.0-alpha (1.20.1).jar` | Java 17，Fabric API，GeckoLib 4.4+ |

两个版本均兼容较旧的 Fabric Loader（1.20.1 需 0.15+，1.21.1 需 0.16+），也适用于使用较旧工具链的整合包。
