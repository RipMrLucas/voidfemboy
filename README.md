# VoidFemboy

A pastel void-themed Fabric mod for Minecraft **1.21.1 and 1.20.1**: void-ore
progression, a true-3D dyeable femboi wardrobe with a **wearable 45-slot hoodie
pocket**, a Cute Station dyeing block, a galaxy title screen, an in-game recipe
Codex, and a few secrets. Meow.

> This repository is for **issues and feature requests only** — the mod's source
> is not published here. Grab the mod from Modrinth / CurseForge.
> The mod is closed source **for now** — it may go open source in the future.

## Features

- **Void armor** — a galaxy-plated set, stronger than diamond, with an emissive
  scrolling galaxy texture and a Regeneration + Strength set bonus.
- **Femboi wardrobe** — a real 3D GeckoLib outfit (cat-ear headband, hoodie,
  dress with a physics-driven skirt + tail, striped thigh-highs, and kitty-paw
  booties). Wear the full set for the cosmetic **Confidence** effect.
- **Femboi Tail & Cat-Ear Headphones** — extra cosmetic slots (Cute Menu, `X`):
  a physics-swayed tail with a white tip, and chunky headphone cups with a
  head-following band. Both dyeable; headphone parts hide in first person.
- **Hoodie pocket** — the hoodie / hoodie-dress carries a **45-slot pocket**
  (9×5). Keybind `N` (default) toggles it open/shut while worn. Contents ride
  the item through closing, relogging, unequipping **and death**.
- **Wear it your way** — hoodie alone (no skirt), dress alone (chest slot), or
  combined hoodie-dress. Sleeves hide while arm warmers are worn.
- **Dyeing** — recolor any femboi piece at the **Cute Station**: 16-color
  rainbow rack + full HSV picker with hex input, per-part colors or
  **Dye All** (armor included). The item-driven paper doll shows exactly which
  piece covers each region. Toggle **striped or solid**, revert with **Clear**.
- **Silent paws** — the paw booties pad around with no footstep sound.
- **Void Codex** — a cute recipe browser opened from the pause menu, over the
  same animated galaxy backdrop as the custom title screen.
- **Blåhaj** — a soft shark plushie block that turns to face you. Right-click
  for a squeak, sneak + right-click to pick it up.
- **Compatibility** — plays nice with Iris/Sodium, First-person Model, JEI, and
  big modpacks (tested in AOF7 on 1.20.1).

## Versions & downloads

Two release lines, same features — pick the one matching your game:

| Minecraft | Jar | Requires |
|---|---|---|
| 1.21.1 | `voidfemboy-0.2.0-alpha.jar` | Java 21, Fabric API, GeckoLib 4.7+ |
| 1.20.1 | `voidfemboy-0.2.0-alpha (1.20.1).jar` | Java 17, Fabric API, GeckoLib 4.4+ |

Both lines work with older Fabric Loaders (1.20.1: 0.15+, 1.21.1: 0.16+) and in
modpacks running older toolchains.
