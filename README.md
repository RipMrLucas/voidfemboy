# VoidFemboy

A cute femboy cosmetic & armor mod for **Minecraft 1.21.1 (Fabric)**.

This repo is for **releases, issue reports and feature requests** — source is not published here (yet).

## Downloads

Grab the latest jar from [Releases](../../releases). Requires:

- Minecraft **1.21.1**
- Fabric Loader
- **Fabric API**
- **GeckoLib** (4.9.2 for 1.21.1)

Optional: Iris/sodium-compatible, plays nice with First Person Model & Not Enough Animations. JEI shows recipe info if installed.

## What's in it

- **Femboi wardrobe** — true-3D GeckoLib outfit: cat-ear headband, hoodie or hoodie-dress with a physics pleated skirt + tail, striped thigh-highs, kitty-paw booties (silent!), and arm warmers (wear via Cute Menu, `X`)
- **Hoodie / dress / combined** — wear the hoodie alone (no skirt = no accidental... surprises), the dress alone, or both as one piece
- **Cute Station** — paper-doll dyeing block: 16-color rainbow rack + full HSV picker, drag a color onto any part, dye everything at once
- **Confidence** — full-set cosmetic effect with a custom icon
- **Void armor** — galaxy-plated set above diamond with Regeneration II + Strength II, void ores in stone & deepslate, prism ore in the deep
- Galaxy title screen, silly rotating tips on menu screens, codex with recipes
